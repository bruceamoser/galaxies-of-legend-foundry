# Rules authority

Bruce owns design decisions. GoL Markdown is authoritative for the workshop; HoL's web workshop is a structural reference. Do not copy HoL-specific game mechanics or treat a workshop convenience as a GoL rule.

Resolve origin grants before level 0 and class grants afterward. A duplicate origin grant is worth one level-0 DP. A duplicate class rank is worth one level-1 DP. This matches the worked Iona ledger. Prerequisites must be satisfied before the purchase. Attribute minimums, signature choices and costs are driven by the imported catalog.

The sheet displays Speed before encumbrance because the current equipment sources do not specify a numeric Speed deduction. Over-capacity loads are flagged for the SA. A gear requirement on an ability is shown in its rules and does not mean the character receives the item.

The prototype uses a local, uncommitted rules snapshot with exact input hashes. Before a public implementation release, pin a reviewed rulebook commit and regenerate the catalog. The browser export is versioned separately from any future Foundry document schema.
